# WAN W3 lite (integrated; built by LAB-075)

**Proven by:** LAB-075 and MS-5. The NTP block sits after `vrf definition MGMT`.

Derived from WAN W3 by LAB-075. Reused by MS-5.

**Nodes:** HQ-WAN1, PROV-INET1, BR1-RTR1 (iol-xe), BR1-PC1 (alpine). The directory also holds the two integration files the lite WAN needs on the neighbouring stages: `HQ-CORE1.cfg` (= `environments/HQ/H3/lite/HQ-CORE1.cfg` + e1/0 to HQ-WAN1 and e1/0.99 MGMT .10/.11, `ip ssh source-interface Ethernet0/1.99`, as MS-3) and `PROV-ISP1.cfg` (= `environments/EDGE/E3/min/PROV-ISP1.cfg` + e0/3 198.51.100.128/31 to PROV-INET1 and the return route for 203.0.113.128/25, as MS-3).

**Changes from W3:** BR1 collapsed (no BR1-ACC1/PC2): BR1-PC1 on BR1-RTR1 e0/2 with `encapsulation dot1Q 10 native` on e0/2.10; OT = Loopback40 10.21.40.1/24 in VRF OT, MGMT = Loopback99 10.21.99.1/24 in VRF MGMT (OSPF 40 / 99, passive). No PROV-PE1: BR1 e0/1 and WAN1 e0/1 shut and unaddressed; BR1's statics 10.10.0.0/16 and 10.50.0.0/16 via 100.64.21.0, WAN1's static 10.21.0.0/16 and its `PROV-ROUTES` redistribution removed. No BR2: WAN1 Tunnel22/Tunnel92 and PROV-INET1 e0/2 and its 203.0.113.160/29 route removed; `WAN1-INET-IN` keeps the BR2 (`.133`) lines. PROV-INET1 e1/0 = 198.51.100.129/31 to PROV-ISP1 e0/3, statics 192.0.2.0/24 and 198.51.100.0/25 via 198.51.100.128. WAN routers as MS-3 CR2's solution: RADIUS group `RADGRP` (server DC-AAA1 10.50.50.52, key `RADKEY123`, `ip vrf forwarding MGMT`, source Ethernet0/2.99 on WAN1 / Loopback99 on BR1), VTY and exec lists `group RADGRP local`, accounting, `radius-server dead-criteria time 5 tries 2`, `deadtime 1`; `logging host 10.50.50.51 vrf MGMT` (trap informational, same source interface); `ntp server vrf MGMT 10.50.50.1 key 1` (HQ-WAN1 no longer `ntp master`). The AAA/logging/NTP block sits after the interfaces in the file: a day-0 `logging host ... vrf MGMT` or `ntp server vrf MGMT ...` placed before `vrf definition MGMT` is dropped silently (the NTP lines sat there until the MS-5 build found them, so the LAB-075 YAML boots without NTP on HQ-WAN1 and BR1-RTR1; LAB-075 validated PASS WITH NOTES without it). No `crypto ipsec security-association replay window-size 1024` (MS-5 CR4 needs it).

**Cabling:** HQ-CORE1 e1/0 - HQ-WAN1 e0/2 (10.10.255.96/31, CORE1 .96; MGMT e1/0.99 10.10.254.10/31, WAN1 .11); HQ-WAN1 e0/0 - PROV-INET1 e0/0 (203.0.113.128/31, INET1 .128); BR1-RTR1 e0/0 - PROV-INET1 e0/1 (203.0.113.130/31, INET1 .130); BR1-RTR1 e0/2 - BR1-PC1 eth0 (10.21.10.0/24, .1 / .101); PROV-INET1 e1/0 - PROV-ISP1 e0/3 (198.51.100.128/31).

**Boot proof (with HQ lite H3, EDGE min E3 and DC lite: 16 nodes incl. DC-SW, DC-SYSLOG1, DC-AAA1):** 16 nodes BOOTED in 105 s. About 3 minutes after start: CORE1 OSPF 8 FULL (v2), 3 (v3), OSPF 99 3; VRRPv3 20/50/99 MASTER on CORE1; GLBP 10 AVG DIST1, two AVFs; HQ-WAN1 OSPF 5 FULL (CORE1, Tunnel21/91/41), OSPF 99 2, OSPF 40 1, IKEv2 3 READY; BR1 OSPF 3 FULL, 99: 1, 40: 1; `test aaa group RADGRP netadmin netpass legacy` successful on both WAN routers; BR1-PC1 reaches HQ-PC1, 10.255.50.1 and the Internet host 192.0.2.200, HQ-PC1 reaches BR1-PC1; DC-SYSLOG1 receives from CORE1, DIST1, DIST2, ACC1, EDGE1, DC-RTR1, HQ-WAN1 and BR1-RTR1. NTP `sys.peer` needs 25-35 min (as H3).
